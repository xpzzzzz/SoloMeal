## 连接演示环境

先按deploy/README.md启动本地隔离Compose环境及演示数据，确认电脑浏览器能打开http://127.0.0.1:18080。不要用生产账号或真实个人小票做故障演练。

默认仅绑定电脑回环地址，手机不能直接访问电脑的127.0.0.1。建议使用装有Android SDK Platform Tools的电脑，通过已授权USB调试连接安卓手机，执行`adb reverse tcp:18080 tcp:18080`，再在手机Chrome打开http://127.0.0.1:18080。仅在本人手机上授权USB调试，测试完成执行`adb reverse --remove tcp:18080`。如改为Wi-Fi局域网，需要显式调整部署绑定和防火墙；本轮不会自动开放公网或修改系统防火墙。

使用私有演示目录credentials.json中的合成账号登录，不将密码贴进聊天。记录手机型号、Android版本、Chrome版本和测试日期。连接方式参考[Android官方反向端口转发说明](https://developer.android.com/develop/ui/views/layout/webapps/access-local-server?hl=zh-CN)和[USB调试说明](https://developer.android.com/tools/adb)。

## 实际任务

1. 查看大米和鸡蛋库存、菜谱及已撤销的做饭记录；检查窄屏换行、软键盘、滚动和按钮是否可用。
2. 手工录入一批明确数量食材。确认前后核对库存差异；连续点击不应重复增加。
3. 上传一张不含个人信息的测试图片，模型关闭时手工补齐小票字段，确认后核对只入库一次。
4. 记录一份做饭并撤销，核对扣减与恢复；刷新、重新登录，旧记录状态应一致。
5. 另建待确认操作（如需真实Agent须先按部署说明配置模型）。确认前断开测试连接，再恢复并刷新登录；检查当前状态，避免把未知结果当失败重新创建。已完成的操作不得重复扣减。
6. 网络故障应实际发生在手机与服务之间。USB reverse连接下，关闭Wi-Fi/开启飞行模式未必切断USB通道，不能据此称弱网已覆盖；可撤销reverse映射后再恢复，记录真实步骤。延迟/丢包场景需实际可控网络或代理，未经测量保持未测，不伪造时延数字。

模型默认关闭是降级演示；有模型的确认/SSE断线恢复是单独验收项，不能用关闭模型页面替代。
